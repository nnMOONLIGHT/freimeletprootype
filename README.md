# Фреймлёт — рабочий прототип

## Структура

```
freimelet/                  ← сам сайт (то, что заливается на GitHub Pages)
  index.html                  вся платформа: разметка + стили + логика в одном файле
  assets/
    logo-icon.png              иконка-плитка (сайдбар, топбар, favicon)
    logo-full.png               полный логотип с названием (можно использовать на других страницах/презентациях)

ai-stylist-nn/               ← нейросеть, обученная с нуля (Python), отдельно от сайта
  styles.py                    описание 8 стилевых классов (палитра, одежда, хобби)
  features.py                  извлечение визуальных признаков из фото (numpy, без сторонних моделей)
  dataset.py                   генератор обучающих изображений (т.к. готового датасета фото нет)
  model.py                     сама нейросеть: прямой и обратный проход, Adam — всё вручную на numpy
  train.py                     обучение + экспорт весов
  export_to_site.py            переносит свежеобученную модель в index.html одной командой
  web_model.json / weights.json  готовые обученные веса (уже встроены в index.html)
```

## Как это работает

Сайт — полностью статический (HTML/CSS/JS), поэтому его можно залить на GitHub Pages
без сервера и базы данных. Но чтобы получить настоящий, а не бутафорский
AI-раздел, нейросеть обучена в Python (см. `ai-stylist-nn/`), а её веса
(числа, а не код) встроены в `index.html` и **выполняются в браузере на
чистом JavaScript** — та же архитектура, тот же прямой проход, без
TensorFlow.js, без OpenAI и без обращения к какому-либо внешнему API.
Всё считается локально на устройстве пользователя.

Если захотите переобучить модель на своих примерах — отредактируйте
`styles.py`/`dataset.py` под свои классы, запустите `train.py`, затем
`export_to_site.py`, и обновлённая модель окажется прямо в сайте.

## Регистрация и «база данных»

Вместо Госуслуг — обычная регистрация (ФИО, дата рождения, город, email,
пароль) с автоматическим определением возраста и, для несовершеннолетних,
блоком согласия родителя (с кнопкой скачивания бланка). Поскольку сайт
статический, аккаунты хранятся в `localStorage` браузера — это честный
рабочий прототип одного браузера/устройства: регистрация, вход, выход и
профиль работают по-настоящему и переживают перезагрузку страницы. Для
продакшена (несколько устройств, реальная база) потребуется backend —
структура кода это допускает: вся работа с "БД" вынесена в несколько
функций (`loadUsers`, `saveUsers`, `submitRegister`, `submitLogin`) наверху
скрипта, их можно заменить на вызовы к своему API, не трогая остальной код.

## Лента творчества

Раздел «Лента творчества» — видео-лента с фильтрами по направлениям.
Она собрана из простого массива `VIDEO_FEED` в `index.html` (карточки со
ссылками на подборки YouTube/VK + один пример живого встроенного видео) —
замените записи в этом массиве на реальные ссылки вашего сообщества,
когда подключите настоящий источник (API соцсети).

## Логотип

Использован предоставленный логотип «Фреймлёт»: иконка — в сайдбаре
(десктоп), в верхней панели (мобильная версия) и как favicon; полный
логотип с подписью — на экране входа.

## Деплой на GitHub Pages

1. Создайте репозиторий, положите в корень содержимое папки `freimelet/`
   (`index.html` и `assets/`).
2. Settings → Pages → Deploy from branch → выберите ветку и `/ (root)`.
3. Подключите свой домен во вкладке Pages при необходимости.
